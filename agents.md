### general description

 - if you want to add something anywhere, ask first, never assume it'll be necessary only because you think so

### style description

- always use navy blue as the main color, white as the second and gold as the third
- every addition in the UI must be responsive

### language description

- the UI is bilingual (Spanish and English, Spanish by default). Every addition in the UI must include its text in both languages (see `client/src/i18n.ts`); never hardcode user-visible text
